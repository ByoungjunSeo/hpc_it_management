# IT 자산관리 시스템 v2.7.0 배포 공지 — 블레이드 섀시 노드 하위 탭

수신: 배포 대상 팀 인프라 담당자 (Docker 운용 가능 전제)

## 1. 개요

v2.7.0은 **블레이드 섀시 팝업 안에서 노드(블레이드)별 정보를 바로 보고 고칠 수 있게** 한 기능 릴리스입니다.
**스키마 변경(DDL)·마이그레이션·신규 환경변수가 없습니다 — 이미지 교체 후 재기동만** 하면 됩니다.

- `it-assets-dist-2.7.0.tar.gz` (전달 번들) · 앱 이미지 `it-assets-2.7.0.tar`
  - sha256(image): `7b8d3107784e481aee80f692e5501465635b0a06e72ba04e54cd4ee425273a82`
  - 적재 전 `sha256sum it-assets-2.7.0.tar` 대조(이미지 `it-assets:2.7.0`).

## 2. 새 기능 — 블레이드 섀시 팝업에서 노드 정보 보기

- 서버실 화면에서 블레이드 섀시를 누르면, 각 탭(기본정보·IP·접속·운영·컴퓨팅 모듈·자산 매칭·전원) 아래에
  **[섀시] [노드1 좌측] [노드2 우측] …** 하위 탭이 생깁니다. 하위 탭을 고르면 그 노드의 정보가 바로 보입니다.
  (하위 탭에 마우스를 올리면 관리번호가 보입니다.)
- 하위 탭은 **한 번 고르면 다른 탭으로 옮겨도 그대로 유지**됩니다(예: 노드1을 고른 채 IP → 모듈로 이동).
- **섀시에 정보가 없는 탭은 첫 노드로 자동 전환**합니다(예: 섀시에 IP가 없으면 IP 탭에서 노드1로). 기본정보·운영정보는 섀시 그대로입니다.
  자동 전환하면 탭 위에 한 줄 안내가 뜹니다.
- 섀시 기본정보에 **“노드 N대: 노드1 좌측(관리번호) · 노드2 우측(관리번호)”**가 표시되고, 누르면 그 노드로 이동합니다.
- **노드별로** 빠른수정(기본·운영·IP·접속)·자산 매칭(스캔→비교→적용)·전원 제어(켜기·끄기·재시작)를 할 수 있습니다.
- **검색·위치 이동**(서버실 검색, 상단 통합 검색, 장비 목록 패널 [정보], `?focus=` 링크)으로 노드를 찾으면,
  **섀시 위치가 강조되고 그 노드가 선택된 상태로** 팝업이 열립니다.
- 일반 장비(블레이드가 아닌 장비) 팝업은 **바뀌지 않았습니다**.

## 3. 안전장치

- 섀시 팝업에서는 편집·스캔·전원 버튼 근처에 **“대상: <관리번호>”**가 표시되어 지금 무엇을 바꾸는지 알 수 있습니다.
- **편집 중 다른 하위 탭을 누르면 확인창**이 뜹니다([확인] 변경 버리고 이동 / [취소] 편집 계속).
- **저장·적용은 시작한 대상에만** 반영됩니다. 저장을 누른 직후 다른 노드로 옮겨도 다른 노드에 저장되지 않습니다.
- 자산 매칭 결과는 **노드마다 따로** 보관됩니다(노드1 스캔 후 노드2를 봤다가 돌아와도 노드1 결과 유지).

## 4. 보안 보완

- 장비 정보 조회 응답(`/assets/:id/json`)의 **노드 목록(children)·부모 섀시(parent) 객체**에 남아 있던
  레거시 `ssh_password` 키를 제거했습니다(v2.4.1에서 누락된 경로). 운영 데이터상 실제 값이 노출된 건은 **0건**입니다.

## 5. 수정된 결함

- **노드 전원 제어 실패**(“랙 정보를 찾을 수 없습니다”) — 노드는 섀시의 랙 경로로 제어하도록 고쳤습니다.
- **섀시 밑 CDU가 노드로 표시**되던 문제 — CDU·칠러는 노드로 보지 않습니다.
- **노드 기본정보의 섀시 표시가 이중으로 이스케이프**되던 문제(특수문자가 깨져 보임).

## 6. 업그레이드 (2.6.x → 2.7.0) — DDL·마이그레이션 없음

**(A) compose 배포**
```bash
DB_CONTAINER_NAME=<DB컨테이너> bash scripts/backup.sh      # (권장) 백업
docker load -i it-assets-2.7.0.tar
# .env에 APP_IMAGE=it-assets:2.7.0 지정 후
docker compose -f docker-compose.prod.yml up -d
```
**(B) systemd(호스트) 배포**
```bash
DB_CONTAINER_NAME=<DB컨테이너> bash scripts/backup.sh
sudo systemctl restart it-assets-v2
```
> **브라우저 Ctrl+F5**: 화면 스크립트·CSS가 바뀌었으므로 재기동 후 강력 새로고침을 권장합니다.
> **롤백**: 데이터·스키마 불변이므로 `APP_IMAGE`를 이전 태그(`it-assets:2.6.0`)로 되돌려 재기동하면 안전합니다.

## 7. 알려진 사항

- **블레이드 노드의 전원 상태 조회는 지원하지 않습니다**(켜기·끄기·재시작은 가능, 명령 후 결과 상태가 표시됨).
  노드는 자체 랙 정보가 없어 랙 단위 상태 조회에 포함되지 않기 때문이며, 서버 변경이 필요한 개선 후보입니다.
- **반납 장비 위치 미해제**([[BUG-29]]), **랙 색 표기**([[BUG-38]]), **수정 폼 IP 무확인 재배정**([[BUG-39]])은 미해결입니다.
- 자산 매칭 적용은 기존과 같이 비트랜잭션입니다 — 한 번에 한 장비씩 적용하고 결과를 확인하세요.
