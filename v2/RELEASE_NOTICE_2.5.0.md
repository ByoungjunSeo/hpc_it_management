# IT 자산관리 시스템 v2.5.0 배포 공지 — 서버실 사용성 개선

수신: 배포 대상 팀 인프라 담당자 (Docker 운용 가능 전제)

## 1. 개요

v2.5.0은 **서버실 화면의 사용성을 넓힌 기능 릴리스**입니다. 자산을 더 빨리 찾고, 찾은 자산의 위치를 바로 보고, 자주 바꾸는 정보(IP·접속정보 등)를 팝업에서 바로 고칠 수 있습니다.
**스키마 변경(DDL)·마이그레이션·신규 환경변수가 없습니다 — 이미지 교체 후 재기동만 하면 됩니다.**

- `it-assets-dist-2.5.0.tar.gz` (전달 번들) · 앱 이미지 `it-assets-2.5.0.tar`
  - sha256(image): `b58df2d62c8ab680d18e74ed35743ad0d4fecff98f6093a8eb433c2390eeb4ea`
  - 적재 전 `sha256sum it-assets-2.5.0.tar` 대조(이미지 `it-assets:2.5.0`).

## 2. 새 기능

### 2-1. 컴퓨팅 모듈까지 찾는 통합 검색
- 장비명·IP·관리번호/자산번호·사용자에 더해 **장착된 컴퓨팅 모듈**로도 검색됩니다.
  - **모델/제조사**(예: `A100`, `H100`, `ConnectX`), **용량**(예: `64GB`, `80GB` — `GiB/TiB` 표기도 인식), **유형 키워드**(`GPU`/`NPU`/`CPU`/`메모리`/`NIC`·`네트워크`/`디스크`·`SSD`/`RAID`/`파워`).
  - 결과는 **[장비] / [IP] / [모듈 장착 장비]** 구역으로 나뉘고, 모듈 매칭 장비에는 **어떤 모듈이 맞았는지 요약 줄**(업체 소유 모듈은 업체 배지)이 붙습니다.
- 숫자만 입력하면 **용량 기준**으로 찾습니다(예: `64` → 64GB 메모리. 640GB 디스크는 과매칭하지 않음).

### 2-2. 검색 결과 클릭 → 위치로 이동·강조
- 통합검색·서버실 검색 결과의 **본문을 클릭**하면,
  - 서버실 화면이면 **페이지 이동 없이** 해당 랙으로 스크롤 + 강조(분할 패널 유지),
  - 다른 화면이면 **서버실 화면으로 이동해** 강조,
  - 랙에 없는 장비(미배치 등)면 **상세 페이지**로 이동합니다.
- **키보드**: ↑/↓로 결과 이동, Enter로 선택, Esc로 닫기.
- 서버실 검색에는 **[모두 표시]** — 현재 결과 중 이 화면 랙에 있는 장비를 한 번에 강조하고, 화면 밖(랙 미배치) 수를 알려줍니다.

### 2-3. 장비 목록 패널
- 서버실 화면 오른쪽에 **장비 목록 패널**(분할 보기). **기본 열림**이며, **숨기기/보이기 상태를 기억**합니다(다음 방문에도 유지). 좁은 화면에서는 오버레이로 전환됩니다.
- 패널 필터에 2글자 이상 입력하면 **그 서버실 범위로 모듈까지 검색**됩니다(예: `H100` → 그 서버실의 H100 장착 장비). 유형 칩으로 추가 필터, 서버실을 바꾸면 자동 재조회.
- 그 서버실에 없고 다른 위치에 있으면 **“이 서버실에 ‘○○’ 장비 없음 · 다른 위치 N건 보기”**로 안내합니다.

### 2-4. 자산 팝업 빠른수정
- 서버실·패널에서 자산 팝업을 열면 **[기본 정보]·[운영 정보]·[IP 정보]·[접속 정보]** 탭에서 **[편집]**으로 바로 고칠 수 있습니다(수정 페이지로 가지 않아도 됨).
- 모듈 탭에는 각 모듈의 **소유(자사/업체)**가 표시됩니다.

## 3. 권한
- **빠른수정은 유지보수 이상**만 가능합니다. **조회(viewer) 계정은 [편집] 버튼이 보이지 않습니다.**

## 4. 안전장치
- **IP 빠른수정**: 다른 장비가 쓰고 있는 IP나 **예약(reserved) IP**로 저장하려 하면 **거부**하고 어떤 장비/상태인지 알려줍니다. IP 풀 밖 주소는 저장은 하되 경고를 표시합니다. 변경은 **한 번에(트랜잭션)** 반영돼 중간 실패 시 원상복구됩니다.
- **접속정보 빠른수정**: 비밀번호 칸을 **비우면 기존 비밀번호가 그대로 유지**됩니다(실수로 지워지지 않음). 삭제는 삭제 표시로만 됩니다.
- **동시 수정 충돌**: 다른 사람이 먼저 저장했으면 **충돌을 알리고** 최신 내용을 다시 불러오게 합니다.
- 비밀번호는 화면·검색·감사 로그 어디에도 **평문으로 나오지 않습니다**(v2.4.1 원칙 유지).

## 5. 업그레이드 (2.4.x → 2.5.0) — DDL·마이그레이션 없음

이미지만 교체하고 재기동하면 됩니다. 데이터·스키마는 바뀌지 않습니다.

**(A) compose 배포**
```bash
# 1) (권장) 백업
DB_CONTAINER_NAME=<DB컨테이너> bash scripts/backup.sh
# 2) 새 이미지 적재
docker load -i it-assets-2.5.0.tar
# 3) .env에 APP_IMAGE=it-assets:2.5.0 지정 후 재기동
docker compose -f docker-compose.prod.yml up -d
```

**(B) systemd(호스트) 배포**
```bash
# 1) (권장) 백업 → 2) 새 코드 반영 → 3) 재기동(이미지 교체·APP_IMAGE 변경 불필요)
DB_CONTAINER_NAME=<DB컨테이너> bash scripts/backup.sh
sudo systemctl restart it-assets-v2
```
> **롤백**: 데이터·스키마가 불변이므로 이전 이미지 태그로 되돌려 재기동하면 안전하게 downgrade됩니다.
> **참고(EJS 뷰 캐시)**: 운영(`NODE_ENV=production`)은 뷰를 캐시하므로 **재기동이 반드시 필요**합니다(화면 변경 반영).

## 6. 알려진 사항
- **수정 페이지(전체 폼)의 IP 저장은 여전히 충돌 검사가 없습니다**([[BUG-39]]). 팝업 빠른수정에는 충돌 검사·트랜잭션이 들어갔지만, 기존 수정 폼 경로는 본 릴리스 범위 밖입니다. IP 변경은 팝업 빠른수정 사용을 권장합니다.
- **업체 소유 스토리지·스위치 등은 랙 화면에서 ‘업체 장비’ 색이 아니라 유형 색으로 표시**됩니다([[BUG-38]], 표시 전용 결함 — 데이터는 정상).
- **사무실 랙에 놓인 장비**는 검색 결과에서 위치 이동 대신 **상세 페이지**로 이동합니다(서버실 화면만 위치 강조를 지원).
- 레거시 `assets.ssh_password` 컬럼은 이번에도 **비저장·응답 제거 상태 유지**(실제 컬럼 폐기는 DDL이 필요해 별도 릴리스로 미룸).
