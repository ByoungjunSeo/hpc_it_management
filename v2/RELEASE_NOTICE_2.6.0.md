# IT 자산관리 시스템 v2.6.0 배포 공지 — 팝업 자산 매칭 · 패널 상태 필터

수신: 배포 대상 팀 인프라 담당자 (Docker 운용 가능 전제)

## 1. 개요

v2.6.0은 **서버실 화면에서 자산 매칭을 바로 하고, 장비 목록을 상태로 거르는** 기능 릴리스입니다.
**스키마 변경(DDL)·마이그레이션·신규 환경변수가 없습니다 — 이미지 교체 후 재기동만** 하면 됩니다.

- `it-assets-dist-2.6.0.tar.gz` (전달 번들) · 앱 이미지 `it-assets-2.6.0.tar`
  - sha256(image): `1145bd55211c31180ab021d6b12a8e486cbb5e32aa52c26a705c32d18b3d9a07`
  - 적재 전 `sha256sum it-assets-2.6.0.tar` 대조(이미지 `it-assets:2.6.0`).

## 2. 새 기능

### 2-1. 서버실 팝업에서 자산 매칭
- 랙/패널에서 장비 팝업을 열면 **[자산 매칭] 탭**에서 바로:
  **스캔**(SSH로 실제 장착 모듈 수집) → **비교표**(등록 ↔ 실제) → **소유 조정**(자사/업체, 수량 분리) → **적용**(등록 모듈 교체·재고 반영) → **미매칭 부품**은 기존 품목에 연결하거나 새로 등록.
- 자산 매칭 화면(`/discovery`)으로 이동하지 않고 팝업 안에서 완결됩니다. (두 화면은 같은 로직을 공유.)

### 2-2. 장비 목록 패널 상태 필터
- 패널 유형 칩 아래 **상태 칩**: 운영중 / 점검중 / 비활성 / 반납 / 폐기(각 건수 표시).
- **기본값: 반납·폐기는 꺼짐**(숨김), 나머지는 켜짐. 다중 토글, **선택은 브라우저에 기억**됩니다.
- 목록 끝에 **“반납 N건·폐기 M건 숨김 [보기]”** — [보기]로 즉시 펼칩니다.
- 적용 범위: 간이 필터(1글자 이하)와 모듈 검색(2글자 이상) 결과 **모두**. 유형 칩 개수도 상태 필터 반영값으로 갱신.
- (배경) 반납 장비가 패널에 남는 것은 반납 시 위치(랙/서버실) 미해제 때문입니다 — **표시만 필터**하며 데이터 정정은 별건입니다.

## 3. [자산 매칭] 탭 노출 조건
- **유지보수 이상** 권한, **서버·스토리지**이면서 **최상위 장비**(블레이드 노드·스위치 등 제외), **접속 가능한 IP**(OS 또는 관리 10.x) 보유 — 세 조건을 모두 만족할 때만 탭이 보입니다. 조회(viewer) 계정에는 보이지 않습니다.

## 4. 안전장치
- **스캔은 DB를 바꾸지 않습니다**(읽기만). 비교표로 확인한 뒤 [적용]할 때만 반영됩니다.
- **동시 적용 보호**: 스캔 후 그 사이 다른 곳에서 먼저 적용되어 모듈 구성이 바뀌면, **적용이 409로 막히고 “다시 스캔” 안내**가 뜹니다(재고·이력 변화 없음). 자산 매칭 화면(`/discovery`)에도 동일 적용.
- **적용 후 재적용 차단**: 같은 스캔 결과로 다시 적용할 수 없고, [다시 스캔] 후에만 가능합니다.
- 비밀번호는 화면·검색·응답 어디에도 평문으로 나오지 않습니다(v2.4.1 원칙 유지).

## 5. 운영 권장(자산 매칭)
1. 첫 적용 전 **백업**.
2. **스캔으로 비교표를 확인**하고, 의도한 차이만 적용.
3. **한 번에 한 장비씩** 적용(적용 경로는 비트랜잭션 — 아래 §7).
4. 적용 후 재고/이력(모듈 인벤토리·이동 이력)이 의도대로 반영됐는지 확인.

## 6. 업그레이드 (2.5.x → 2.6.0) — DDL·마이그레이션 없음

**(A) compose 배포**
```bash
DB_CONTAINER_NAME=<DB컨테이너> bash scripts/backup.sh      # (권장) 백업
docker load -i it-assets-2.6.0.tar
# .env에 APP_IMAGE=it-assets:2.6.0 지정 후
docker compose -f docker-compose.prod.yml up -d
```
**(B) systemd(호스트) 배포**
```bash
DB_CONTAINER_NAME=<DB컨테이너> bash scripts/backup.sh
sudo systemctl restart it-assets-v2
```
> **브라우저 Ctrl+F5**: 새 JS 파일(`public/js/discovery-core.js`)이 추가되므로 재기동 후 강력 새로고침 권장.
> **롤백**: 데이터·스키마 불변이므로 이전 이미지 태그로 되돌려 재기동하면 안전합니다.

## 7. 알려진 사항
- **자산 매칭 적용은 비트랜잭션**입니다(기존 `/discovery`와 동일) — 중간 실패 시 일부만 반영될 수 있으니 한 번에 한 장비씩 적용하고 결과를 확인하세요.
- **반납 장비 위치 미해제**([[BUG-29]]): 패널에서는 상태 필터로 숨기지만 데이터 정정은 미해결.
- **랙 색 표기**([[BUG-38]], 업체 소유가 유형 색으로 표시)·**수정 폼 IP 무확인 재배정**([[BUG-39]])은 미해결(팝업 빠른수정 IP는 충돌 검사 적용됨).
